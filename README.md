# 윤은미 | 프로젝트윤

업무의 불편을 구체적인 AI 활용 과제와 작은 도구로 바꾸는 일을 합니다.

경영학을 전공했으며, 고객 요청 정리·AI 활용자료 제작·업무 사전진단·서비스 시연 경험을 쌓고 있습니다. 업무 흐름을 이해하고, 결과를 검증하며, 다른 사람이 다시 사용할 수 있게 만드는 과정에 집중합니다.

## 먼저 살펴볼 작업

| 작업 | 살펴볼 내용 | 공개 자료의 범위 |
|---|---|---|
| [법률 절차 길잡이](https://github.com/yuneunmi814-cmyk/legal-navigator-mcp) | 일상어로 설명한 문제를 절차·서식·출처 안내로 연결 | 공개 코드와 설계 설명 |
| [기업 마케팅 업무 사전진단](cases/marketing-diagnosis.md) | 후보 업무 선정, 작은 시험 계획, 검수 기준 | 공개자료 기반 제안의 익명 요약 |
| [AX 진단 도구](cases/ax-demo.md) | 업무 추천과 자료 부족 시 보류 조건 | 가상자료 기반 시연의 설계 요약 |
| [AI 활용 교육 지원](cases/learning-support.md) | 결과물 전달 이후 다시 따라 할 수 있는 자료 구성 | 고객을 식별하지 않는 작업 요약 |

## 작업을 정리하는 기준

- 어떤 문제를 해결하려 했는지, 왜 그 범위를 골랐는지 설명합니다.
- 제 판단과 작업, 협업자와 AI 도구의 기여를 구분합니다.
- 제안서 작성·작동 시연·고객 전달·실제 운영을 구분합니다.
- 확인한 결과와 아직 확인하지 못한 부분을 함께 적습니다.

AI 도구의 도움을 받아 코드와 자료를 만들고 있습니다. 사용한 기술 목록보다 제가 설명할 수 있는 요구사항, 수정 과정, 검수 기준을 중심으로 작업을 소개합니다.
