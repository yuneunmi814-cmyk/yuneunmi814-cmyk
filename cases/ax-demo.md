# AX 진단 도구: 추천 전에 확인할 조건

**상태: 규칙 기반 작동 시연. 외부 AI 연결·실제 고객 운영 전 단계입니다.**

## 문제와 접근

AI를 써보고 싶은 사람이 처음 시험할 업무를 고르도록 돕는 시연입니다. 무엇이든 추천하기보다, 자료가 준비되어 있는지와 확인이 필요한 조건을 먼저 구분했습니다.

## 시연 구성

질문 8개로 업무와 자료 상태를 확인하고, 먼저 시험할 업무를 최대 2개 추천합니다. 학원 리포트 예시에는 가상 학생 5명을 사용했습니다. 초안 작성 3건과 자료 확인 보류 2건으로 나누어, 누락된 정보를 임의로 채우지 않는 흐름을 보여줍니다.

## 역할과 검증 범위

저는 활용 방향과 수정 요청을 제시했습니다. AI 에이전트는 코드 작성과 규칙 검사, 화면 확인을 수행했습니다. 에이전트 검사 기록과 제가 독립적으로 구현·검사한 경험은 구분합니다.

자료 누락·충돌 시 보류하고, 내용 수정 시 이전 검토 상태를 해제하는 흐름을 구성했습니다. 이 기록은 내부 시연이며 실제 고객 만족도·오류율·운영 안정성의 증거는 아닙니다.
